# Task 13 — Focus & Distraction Scoring Technical Documentation

## 1. Objective

Task 13 implements a clean Focus and Distraction scoring presentation layer for FocusSense AI using the existing Task 11 scikit-learn ML pipeline and Task 12 student insight flow.

Key Scope Boundaries Enforced:
- **Reuse Existing Task 11 Models**: Used persisted `focus_regressor.joblib` (`RandomForestRegressor`) and `distraction_classifier.joblib` (`RandomForestClassifier`). No model retraining was performed.
- **Focus Score Bounding**: Focus predictions are safely bounded to $[0.0, 100.0]$ at the inference layer via `np.clip(raw_focus, 0.0, 100.0)`.
- **Distraction Classification Validation**: Distraction levels remain strictly `LOW`, `MEDIUM`, or `HIGH`. If an invalid class is produced, an explicit `ValueError` is raised rather than silently masking the defect.
- **No Added Complexity**: No distraction confidence scores, `predict_proba` distribution objects, or complex Deep Learning models were added to schemas or databases.
- **Real-Data Gate Preservation**: Inference runs **only** when `activity_count >= 1` and `total_duration_seconds > 0.0`. No fake scores are generated for empty/unstarted sessions.


## 3. Focus & Distraction Scoring Presentation

### A. Focus Score
- **Inference Bounding**: `focus_score = round(float(np.clip(raw_focus, 0.0, 100.0)), 1)`
- **UI Representation**: Rendered as `XX / 100` with progress bars and an `"AI Focus Score"` badge.
- **Interpretation**: Higher values indicate sustained attention stability and higher productive time ratios.

### B. Distraction Level
- **Allowed Categories**: `LOW`, `MEDIUM`, or `HIGH`
- **Validation**:
  ```python
  distraction_level = str(distraction_model.predict(X_scaled)[0])
  if distraction_level not in ("LOW", "MEDIUM", "HIGH"):
      raise ValueError(f"Invalid distraction class predicted: {distraction_level}")
  ```
- **UI Representation**: Color-coded badges (`LOW`: green, `MEDIUM`: amber, `HIGH`: red) labeled `"AI Distraction Level"`.
